Pengaturan Repo
Token ini tidak pernah disimpan permanen — cuma dipegang browser selama tab ini terbuka, hilang begitu di-refresh/ditutup. Cara buat token (sekali saja, lalu simpan sendiri di tempat aman):
  1. GitHub → foto profil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access: pilih "Only select repositories" → pilih tekajeschool
  3. Permissions → Repository permissions → Contents → set ke Read and write
  4. Generate token, copy, tempel di kolom atas
