Aplikasi Android (APK)

Pola Kunci Perangkat

Daftar perangkat yang sudah membuat pola kunci, lengkap dengan pola asli yang digambar, jenis/model perangkat, dan IP address saat pola itu dibuat. Klik ikon gembok untuk reset pola perangkat itu (misal siswa lupa polanya) — begitu direset, perangkat itu wajib membuat pola baru saat dibuka lagi.

Sebagian entri lama (dibuat sebelum fitur pelacakan ini aktif) belum punya data Pola/Perangkat/IP. Entri baru setelah update akan otomatis lengkap.

File Web (GitHub)

Pengaturan Repo
Token ini tidak pernah disimpan permanen — cuma dipegang browser selama tab ini terbuka, hilang begitu di-refresh/ditutup. Cara buat token (sekali saja, lalu simpan sendiri di tempat aman):
  1. GitHub → foto profil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access: pilih "Only select repositories" → pilih tekajeschool
  3. Permissions → Repository permissions → Contents → set ke Read and write
  4. Generate token, copy, tempel di kolom atas
